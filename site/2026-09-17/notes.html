直接平均时，每块占 25%，A 胜出。但这个比较还没有回答：如果块 4 这种阶段以后出现得更频繁，A 的优势还在吗？

教学类比 可以把四个时间块想成四种历史路况，损失是车辆在其中的表现；平均分默认每种路况占四分之一。类比到此为止：真实时间块混合了潜在状态，还可能有时间依赖，不是四次独立抽样。

2. Λ：先声明未来可以偏到什么程度

输入是四个块的风险与一个声明的 Λ。输出不是预测概率，而是一组允许的未来比例。Λ=2 的意思是：每块原占 25%，未来最多占 50%，所有块的比例仍须加起来为 100%。

w₁ + w₂ + w₃ + w₄ = 1
每个 wⱼ ≥ 0；每个 wⱼ ≤ Λ / 4

作者假设 A3 在事先声明的块长度 b 上约束未来状态占比；A2 要求同一状态下的机制不变，或把偏离写成单独的误差项。今天先取机制偏差为零。Λ 与块长度都要先说清楚，不能看完结果再把 Λ 调成有利数值。出处：A3

Λ 不能靠历史数据估出一个对未来必然成立的值。历史可以反驳某些过强声明，却不能担保未来仍在这个范围里。稳定的市场机制也不意味着有限时间窗里的占比完全不变。出处：§5

3. 怎么找最坏情况：把权重搬向较差的块

固定 Λ=2。每块最多放 0.5 的权重；为了得到最坏损失，先给损失最大的块放满，再给次差的块，直到总权重达到 1。

  1. A 的最差块是块 4，损失 9，放入权重 0.5。
  2. 还剩 0.5，放到损失为 1 的任意一个块；demo 在同分时按原顺序选择块 1。
  3. 最终权重是 [0.5, 0, 0, 0.5]，损失为 0.5×1 + 0.5×9 = 5。
  4. B 同样得到 [0.5, 0, 0, 0.5]，损失为 0.5×3 + 0.5×4 = 3.5。

于是平均记分选择 A，受约束的最坏情况比较选择 B。这说明两种目标可以改变排序；不意味着每一组数据都一定会改变排序。

最小推导 如果较差的块还没装满，而较好的块上仍有权重，把少量权重从较好块搬到较差块，只会提高或保持损失。不断搬到不能再搬，就得到上述贪心解。模型各自取自己的最坏权重，比较的是各自的最坏风险，而不是在断言未来真的选择了这个权重。

4. 这就是本论文记号里的 CVaR

R⁺(h) ≤ max Σⱼ wⱼ Rⱼ(h) = CVaR₁/Λ(R₁,…,Rᴮ)
            w ≥ 0, Σw = 1, wⱼ ≤ Λ/B

等价的有限情形：minₜ [t + (Λ/B) Σⱼ max(Rⱼ − t, 0)]

原文结果 在 A2、A3 下，定理 6.2 把未来的条件期望风险上界写成上述最坏加权风险，且此上界能在允许的未来中达到。我们演示的是它的四个等权原子版本。出处：定理 6.2

这里 CVaR 的下标 1/Λ 是“最差尾部所占的比例”：Λ=2 就看最差一半。它不同于把 95% 当作置信水平的另一种常见记号。尾部包含不到整数个块时，边界块只取一部分权重，不要直接向上取整后平均。Λ=1 回到平均；四块算例在 Λ=4 就到达最差单块。

5. 把概念写成一个可执行的小需求

问题：验证有权重上限的最坏加权损失，是否等于上尾平均，以及何时改变候选排序。

输入与假设：人工损失数组 A/B；四块等权；Λ≥1；损失视作已知的理论块风险；只改变已有块的权重。

输出：每步分配的权重、加权损失和排序；正常例 Λ=2、边界例 Λ=1 与 Λ=4，以及未见状态反例。

正确性依据：权重非负、总和为 1、不超过 Λ/4；另用枚举可行多面体顶点的独立解法核对最优值。

有意省略：模型拟合、真实行情、交易成本、purge/embargo、有限样本与搜索误差、实际仓位。它只验证一个确定性的数学机制。

6. 两个必须守住的边界

未见状态：假设未来出现一个从没出现在历史中的状态，损失为 20。怎样重新分配历史 [1,1,1,9] 的权重，都造不出这个状态。把 Λ 提到 4 只会算出 9，覆盖假设已经失败；更保守的权重不能补回缺失的历史支持。

理论风险 ≠ 实测块分数：定理里的 Rⱼ 是潜在状态下的条件期望风险，实际回测只能拿到含噪声的块损失估计。挑最差尾部还可能挑中了噪声。有限样本、依赖、状态表示误差和多次搜索都要另付误差代价，不能把 demo 的精确等式直接变成真实收益保证。出处：§8.4、§13.2
